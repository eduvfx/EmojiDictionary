Emoji Dictionary — Tutorial passo a passo

Cadeira: Desenvolvimento para Dispositivos Móveis · Ficha 3 (Storyboard / UIKit) · Xcode, Swift, Interface: Storyboard
Como usar este tutorial. Descreve exactamente o que fazer à mão no Xcode, pela ordem da ficha (secções 0 a 6). O projecto entregue em EmojiDictionary/ já está completo — se quiseres seguir os passos, cria um projecto novo com o mesmo nome (File > New > Project… > iOS > App, Interface Storyboard) e segue da secção 0. Não é preciso apagar nada do projecto entregue: os passos abaixo produzem-no de raiz. Nos passos em que a ficha manda escolher tipo de letra por text style (Large Title / Headline / Subheadline), o projecto entregue usa o tamanho equivalente em pontos (34 / 17 semibold / 15) — é o mesmo resultado visual e evita depender do catálogo de estilos.

0. Configuração do projecto

  1. File > New > Project… → iOS → App → Next.
  2. Product Name: EmojiDictionary; Interface: Storyboard; Language: Swift → Next → escolhe a pasta do projecto → Create.
  3. Confirma no Project Navigator (⌘1) que existem AppDelegate.swift, SceneDelegate.swift, ViewController.swift e Main.storyboard.
Resultado esperado: projecto novo que corre no simulador mostrando uma cena em branco.

1. Modelo

  1. File > New > File… → Swift File → Next → nome Emoji.swift → Create.
  2. Escreve o struct Emoji com os quatro campos.
  3. Acrescenta a extension Emoji com static var sampleEmojis e os seis emojis da ficha.
struct Emoji {
    var symbol: String
    var name: String
    var description: String
    var usage: String
}

extension Emoji {
    static var sampleEmojis: [Emoji] {
        [
            Emoji(symbol: "😀", name: "Grinning Face", description: "A typical smiley face.", usage: "happiness"),
            Emoji(symbol: "😕", name: "Confused Face", description: "A puzzled face.", usage: "unsure"),
            Emoji(symbol: "😍", name: "Heart Eyes", description: "Loves something.", usage: "love"),
            Emoji(symbol: "🧑‍💻", name: "Developer", description: "Working on Mac.", usage: "software, coding"),
            Emoji(symbol: "🐢", name: "Turtle", description: "Slow but steady.", usage: "slow"),
            Emoji(symbol: "📚", name: "Books", description: "Stack of books.", usage: "study")
        ]
    }
}
Resultado esperado: o ficheiro compila sem erros (não tem UIKit) e Emoji.sampleEmojis.count daria 6.

2. Navegação e lista principal

  1. Em Main.storyboard, selecciona a cena View Controller (canvas ou Document Outline) e carrega em Delete.
  2. Abre a Object Library (⇧⌘L), procura Navigation Controller e arrasta-o para o canvas.
  3. Selecciona o Navigation Controller → Attributes Inspector (ícone do slider) → liga Is Initial View Controller.
  4. File > New > File… > Cocoa Touch Class → Class EmojiTableViewController, Subclass of UITableViewController, Language Swift → Next → Create.
  5. Selecciona a cena do Table View Controller → Identity Inspector (ícone do selo) → Class = EmojiTableViewController.
  6. No Document Outline, abre EmojiTableViewController, selecciona o Navigation Item → Attributes Inspector → Title = Emoji Dictionary.
  7. Arrasta um Bar Button Item para a direita da barra → Attributes Inspector → System Item = Add.
Resultado esperado: a app arranca com barra de navegação, título “Emoji Dictionary” e o botão +; a lista ainda está vazia (o emojis começa em Emoji.sampleEmojis na secção 4).

3. Célula personalizada e layout

  1. Selecciona o Table View dentro de EmojiTableViewController → Attributes Inspector → confirma Prototype Cells = 1.
  2. Selecciona a célula protótipo: Identity Inspector → Class = EmojiTableViewCell; Attributes Inspector → Identifier = EmojiCell.
  3. Arrasta três Labels para a Content View: símbolo (fonte grande, 34), nome (17 semibold), descrição (15, Text Color = Secondary Label, Lines = 0, Line Break = Word Wrap).
  4. Selecciona nome + descrição → Editor > Embed In > Stack View → Spacing 2, Alignment Leading.
  5. Selecciona símbolo + o stack vertical → Editor > Embed In > Stack View → Spacing 12, Alignment Center.
  6. Selecciona o stack horizontal → Add New Constraints (ícone do quadrado) → Leading 16, Trailing 16, Top 8, Bottom 8.
  7. Selecciona o symbolLabel → Size Inspector → Horizontal Content Hugging Priority = 252, Horizontal Compression Resistance = 751.
  8. Abre o Assistant Editor (botão Editor Options → Assistant) com EmojiTableViewController.swift visível, escreve a classe EmojiTableViewCell no topo do ficheiro e faz Control-drag de cada label para o respectivo @IBOutlet.
class EmojiTableViewCell: UITableViewCell {
    @IBOutlet weak var symbolLabel: UILabel!
    @IBOutlet weak var nameLabel: UILabel!
    @IBOutlet weak var descriptionLabel: UILabel!

    func update(with emoji: Emoji) {
        symbolLabel.text = emoji.symbol
        nameLabel.text = emoji.name
        descriptionLabel.text = emoji.description
    }
}
Resultado esperado: a célula mostra o emoji grande à esquerda e nome/descrição à direita; os quatro outlets aparecem ligados no Connections Inspector.

4. Ecrã de lista (implementação)

  1. Em EmojiTableViewController, declara var emojis: [Emoji] = Emoji.sampleEmojis.
  2. Em viewDidLoad(), instala navigationItem.leftBarButtonItem = editButtonItem e liga a altura automática (automaticDimension + estimatedRowHeight = 60.0).
  3. Implementa numberOfSections(in:), tableView(_:numberOfRowsInSection:) e tableView(_:cellForRowAt:) (dequeue com o identifier EmojiCell, cell.update(with:), showsReorderControl = true).
  4. Implementa tableView(_:commit:forRowAt:) (remove da array + deleteRows(at:with: .fade)) e tableView(_:moveRowAt:to:) (remove + insert na array).
override func tableView(_ tableView: UITableView, cellForRowAt indexPath: IndexPath) -> UITableViewCell {
    let cell = tableView.dequeueReusableCell(withIdentifier: "EmojiCell", for: indexPath) as! EmojiTableViewCell
    let emoji = emojis[indexPath.row]
    cell.update(with: emoji)
    cell.showsReorderControl = true
    return cell
}
Resultado esperado: a lista mostra os 6 emojis, cada linha ajusta a altura ao conteúdo, o Edit liga o modo de edição, o swipe revela Delete e as linhas podem ser arrastadas para reordenar.

5. Ecrã Add / Edit (formulário estático)

  1. Arrasta um novo Table View Controller para Main.storyboard → Editor > Embed In > Navigation Controller.
  2. File > New > File… > Cocoa Touch Class → AddEditEmojiTableViewController, subclasse de UITableViewController; depois Identity Inspector → Class = essa classe.
  3. Table View → Attributes Inspector → Content = Static Cells, Style = Inset Grouped, Sections = 4; em cada secção põe Rows = 1.
  4. Headers: Symbol, Name, Description, Usage. Em cada célula arrasta um Text Field com os placeholders The emoji, The emoji's name, Describe this emoji, When do you use it? e fixa-o com Leading 16, Trailing 16, Center Vertically.
  5. Na barra: Bar Button Item à esquerda com título Cancel; outro à direita com System Item = Save.
  6. Liga os outlets symbolTextField, nameTextField, descriptionTextField, usageTextField e saveButton.
  7. Liga o Cancel a cancelButtonTapped(_:) e, para cada um dos quatro campos, faz Control-drag para textEditingChanged(_:) com o evento Editing Changed.
func updateSaveButtonState() {
    let symbol = symbolTextField.text?.trimmingCharacters(in: .whitespaces) ?? ""
    let name = nameTextField.text?.trimmingCharacters(in: .whitespaces) ?? ""
    let description = descriptionTextField.text?.trimmingCharacters(in: .whitespaces) ?? ""
    let usage = usageTextField.text?.trimmingCharacters(in: .whitespaces) ?? ""

    saveButton.isEnabled = !symbol.isEmpty && !name.isEmpty && !description.isEmpty && !usage.isEmpty
}
Resultado esperado: o formulário abre com 4 secções e um campo por secção; o Save está desactivado até os quatro campos terem texto; o Cancel fecha o formulário.

6. Navegação, segues e passagem de dados

  1. Control-drag do botão + para o Navigation Controller que embute o formulário → Present Modally → Attributes Inspector → Identifier AddEmoji.
  2. Control-drag da célula protótipo (EmojiCell) para o mesmo Navigation Controller → Present Modally → Identifier EditEmoji.
  3. Acrescenta a EmojiTableViewController o prepare(for:sender:) que obtém segue.destination as! UINavigationController → topViewController as! AddEditEmojiTableViewController e, no caso "EditEmoji", passa emojis[tableView.indexPathForSelectedRow!.row].
  4. Acrescenta o @IBAction func unwindToEmojiTableView(_ segue: UIStoryboardSegue) com o guard segue.identifier == "saveUnwind" e as duas ramificações (actualizar vs inserir).
  5. Control-drag do botão Save para o ícone Exit da cena do formulário → escolhe unwindToEmojiTableView: → Attributes Inspector → Identifier saveUnwind.
  6. No prepare(for:sender:) do formulário, constrói o Emoji a partir dos quatro campos quando o identifier é saveUnwind.
Resultado esperado: + abre o formulário vazio e o Save acrescenta uma linha no fim; tocar numa linha abre o formulário preenchido e o Save substitui essa linha; Cancel fecha sem alterações.
