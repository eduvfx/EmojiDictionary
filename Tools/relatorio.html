0. Configuração do projecto

O projecto segue exactamente o template da ficha: iOS > App, nome EmojiDictionary, Interface Storyboard, linguagem Swift.

  1. File > New > Project… → template iOS > App.
  2. Nome EmojiDictionary; Interface Storyboard; Language Swift.
  3. Ficheiros gerados: AppDelegate.swift, SceneDelegate.swift, ViewController.swift, Main.storyboard.
Resultado esperado: projecto que compila e mostra uma cena vazia; aqui o ViewController inicial foi eliminado na secção 2.

1. Modelo

O modelo é um struct com os quatro campos que a célula e o formulário mostram, mais uma extensão com os seis emojis de exemplo (fonte única de dados da lista).

struct Emoji {
    var symbol: String
    var name: String
    var description: String
    var usage: String
}

extension Emoji {
    static var sampleEmojis: [Emoji] { [ /* 6 Emoji(symbol:name:description:usage:) */ ] }
}
Resultado esperado: Emoji.sampleEmojis.count == 6, verificado pelo script (conta os Emoji(symbol: no ficheiro).

2. Navegação e lista principal

A cena “View Controller” do template foi apagada e substituída por um Navigation Controller com um Table View Controller como root, ligado à classe EmojiTableViewController. O título da barra é Emoji Dictionary e o botão direito é o System Item Add.

  1. Seleccionar a cena “View Controller” em Main.storyboard e apagar (Delete).
  2. Object Library (⇧⌘L) → arrastar Navigation Controller (cria o Table View Controller como root).
  3. Navigation Controller → Attributes Inspector → Is Initial View Controller ✔.
  4. File > New > File… > Cocoa Touch Class → EmojiTableViewController, subclasse de UITableViewController.
  5. Identity Inspector do root → Class = EmojiTableViewController.
  6. Navigation Item → Attributes Inspector → Title = Emoji Dictionary.
  7. Arrstas um Bar Button Item para a direita da barra → Attributes Inspector → System Item = Add.
Resultado esperado: ao correr, a app abre já dentro de um UINavigationController com a barra “Emoji Dictionary”, o botão + à direita e o Edit à esquerda (o Edit é instalado em código, §4).

3. Célula personalizada e layout

A célula é a classe EmojiTableViewCell (declarada no topo de EmojiTableViewController.swift) com três labels: símbolo, nome e descrição. O layout usa um stack vertical (nome + descrição) embutido num stack horizontal (símbolo + vertical), fixo às margens da Content View.

  1. TableView → Prototype Cells = 1; célula → Identity: Class EmojiTableViewCell, Identifier EmojiCell.
  2. Três labels na Content View: símbolo (Large Title / 34), nome (Headline / 17 semibold), descrição (Subheadline / 15, Secondary Label, Lines = 0, Word Wrap).
  3. Nome + descrição → Editor > Embed In > Stack View (vertical, spacing 2, alignment Leading).
  4. Símbolo + stack vertical → Embed In > Stack View (horizontal, spacing 12, alignment Center).
  5. Stack horizontal → Add New Constraints → Leading 16, Trailing 16, Top 8, Bottom 8.
  6. symbolLabel → Size Inspector → Hugging horizontal 252, Compression Resistance 751.
  7. Assistant Editor: Control-drag de cada label para symbolLabel, nameLabel, descriptionLabel.
Resultado esperado: cada linha mostra o emoji grande à esquerda e, à direita, o nome com a descrição por baixo; as linhas crescem em altura quando a descrição ocupa duas linhas (altura automática).

4. Ecrã de lista (implementação)

O controlador define as três fontes de dados, a remoção com swipe-to-delete, o reordenamento com o modo de edição e a altura automática das células.

override func viewDidLoad() {
    super.viewDidLoad()
    navigationItem.leftBarButtonItem = editButtonItem
    tableView.rowHeight = UITableView.automaticDimension
    tableView.estimatedRowHeight = 60.0
}
Resultado esperado: deslizar para a esquerda revela Delete; o botão Edit mostra os badges de remoção e as pegas de reordenamento; nenhuma alteração é feita só na view — a array é sempre actualizada primeiro.

5. Ecrã Add / Edit (formulário estático)

O segundo controlador é um UITableViewController com células estáticas (4 secções, 1 linha cada), apresentado dentro do seu próprio Navigation Controller para ter barra com Cancel e Save.

  1. Novo Table View Controller → Editor > Embed In > Navigation Controller.
  2. Identity Inspector → Class = AddEditEmojiTableViewController.
  3. TableView → Attributes Inspector → Content = Static Cells, Style = Inset Grouped, Sections = 4; cada secção com Rows = 1.
  4. Headers: Symbol, Name, Description, Usage; um Text Field em cada célula com os placeholders acima, fixo com Leading 16, Trailing 16, Center Vertically.
  5. Barra: Cancel à esquerda (title Cancel) e Save à direita (System Item Save).
  6. Ligações: 4 text fields + saveButton (outlets); Cancel → cancelButtonTapped:; os 4 campos → textEditingChanged: com o evento Editing Changed.
Resultado esperado: o Save começa desactivado e só fica azul quando os quatro campos têm texto (sem contar espaços); em modo de edição o formulário abre preenchido com o emoji escolhido e o título passa a “Edit Emoji”.

6. Navegação, segues e passagem de dados

Duas apresentações modais (Add e Edit) e um unwind segue para devolver os dados: o prepare(for:) do formulário constrói o Emoji, e o unwindToEmojiTableView(_:) da lista decide entre actualizar e inserir.

  1. AddEmoji: Control-drag do botão + para o Navigation Controller do Add/Edit → Present Modally → Identifier AddEmoji.
  2. EditEmoji: Control-drag da célula protótipo para o mesmo Navigation Controller → Present Modally → Identifier EditEmoji.
  3. prepare(for:) da lista: segue.destination as! UINavigationController → topViewController as! AddEditEmojiTableViewController; no Edit passa emojis[indexPathForSelectedRow.row].
  4. saveUnwind: Control-drag do botão Save para o ícone Exit da cena → unwindToEmojiTableView: → Attributes Inspector → Identifier saveUnwind.
  5. prepare(for:) do formulário: com segue.identifier == "saveUnwind", monta Emoji(symbol:name:description:usage:) a partir dos quatro campos.
Resultado esperado: + abre um formulário vazio (Save bloqueado até estar tudo preenchido) e adiciona a linha no fim; tocar numa linha abre o formulário preenchido e o Save substitui a linha na mesma posição; Cancel fecha sem alterar nada.
